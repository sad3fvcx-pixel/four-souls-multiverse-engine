# Four Souls Multiverse Engine
# Trigger Registry

Version: 1.0 (Draft)

---

# Назначение

Trigger — событие, которое начинает выполнение способности.

Каждая способность карты начинается именно с Trigger.

Один Trigger может запускать любое количество Effect.

Карты никогда не опрашиваются постоянно.
Движок лишь рассылает события.

Имена триггеров совпадают со значениями `EventType`: карта, объявляющая
`"trigger": "after_damage"`, реагирует на `EventType.AFTER_DAMAGE` без
таблицы соответствий между ними.

---

# Область действия

Триггер жизненного цикла карты (`on_enter`, `on_play`, `on_activate`,
`treasure_*` и родственные) срабатывает только для той карты, которой
событие касается. Активация одного предмета не запускает способности
остальных.

Остальные триггеры — начало хода, смерть монстра — касаются всего стола.

Карта может переопределить поведение полем `scope`: `"self"` или `"any"`.
